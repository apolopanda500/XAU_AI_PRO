## 7. Arquitetura Atual

```
Frontend (React + TypeScript + Tauri)
    ↓ WebSocket (porta 9002) + HTTP API (porta 9003)
Core Backend (Rust)
    ↓ HTTP local (porta 9001)
MT5 EA (MQL5) — Executor Real
    ↓
Adaptadores: Binance, MEXC, Bybit, OKX
```

### Componentes
| Camada | Local | Responsabilidade |
|---|---|---|
| Desktop PC | frontend/ + frontend/src-tauri/ | Interface React, Tauri, notificações |
| Core | core/ | Sessão MT5, heartbeat, WebSocket, despacho |
| Gateway | backend/fastapi_gateway.py + backend/mt5_gateway.py | API local, leitura MT5, contratos |
| Execução | backend/*_execution.py | Adaptadores MT5, Binance, MEXC, Bybit, OKX |
| Risco | backend/risk_gate.py | Limites de volume, perda, exposição |
| Auditoria | backend/audit_log.py + backend/intent_log.py | Registro sem segredos |
| Telemetria | backend/watchdog.py + backend/guardian_engine.py | Heartbeat, saúde, eventos |
| Empacotamento | *.spec, scripts/, installer/ | PyInstaller, Tauri, MSI, NSIS |
| EA | Experts/ | Intocável |
