## Overview

XAU_AI_PRO is an automated trading system for MetaTrader 5 that merges classical technical analysis (EMA, RSI, ADX, ATR, candle patterns) with AI-based predictions generated by a Python RandomForest model. The system was built through five iterative phases (audit, multi-symbol support, risk management, effective AI integration, and GitHub registration).

The MQL5 Expert Advisor receives AI predictions via JSON files produced by the Python pipeline, combines them with technical signals, and makes trade decisions weighted **50% AI / 50% traditional signals**.

## Features

### V1.0 (Stable)

- **Multi-symbol trading** — Operates on XAU/USD and any additional symbols configured in MetaTrader 5.
- **AI-driven signal weighting** — AI contributes 50% to the market score; includes AI Veto and AI lot multiplier.
- **Robust risk management** — Equity protection, daily loss limits, drawdown-based lot scaling, break-even with ATR, trailing stop with ATR.
- **Memory-safe MQL5 modules** — All indicator handles are properly released on every code path.
- **Python ML pipeline** — RandomForest with 300 estimators, class-weighted, 18 engineered features.
- **JSON-based prediction feed** — MQL5 reads `prediction_{SYMBOL}.json` files produced by `predict.py`.

### V1.1 (Planned)

- Capital preservation enhancements (volatility-adjusted position sizing, max drawdown monitoring)

### V2.0+ (Planned)

- XAU AI Studio — Windows desktop application
- Web portal with public API

## Installation

### Prerequisites

- **MetaTrader 5** (Windows)
- **Python 3.12+**
- **Git**

### 1. Clone the repository

```bash
git clone https://github.com/apolopanda500/XAU_AI_PRO.git
cd XAU_AI_PRO
```

### 2. Python dependencies

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 3. MetaTrader 5 setup

1. Copy the `MQL5/` contents into your MetaTrader 5 `MQL5` folder (or compile directly in MetaEditor).
2. Ensure the EA's `Data/` folder is writable by MT5.
3. Attach the EA to a chart of your desired symbol.

## Usage

### Training the AI model

```bash
cd Python/
python train.py
```

This reads the dataset from `MQL5/Files/Data/dataset.csv`, engineers 18 features, trains a RandomForestClassifier (300 estimators), and saves `model.pkl`.

### Running predictions

```bash
cd Python/
python predict.py
```

Generates `prediction_{SYMBOL}.json` for each symbol in the dataset, placed in `MQL5/Files/Data/`.

### In MetaTrader 5

Attach `XAU_AI_PRO` to a chart. The EA will:

1. Save market data for all configured symbols.
2. Read the corresponding `prediction_{SYMBOL}.json` (if available).
3. Combine AI prediction with technical signals (50% AI / 50% traditional).
4. Apply risk management rules.
5. Execute trades with proper position sizing.

## AI Integration

```
[MT5 Market Data] → EA saves dataset.csv → [Python train.py] → model.pkl
                                                              ↓
[MT5 Data] → EA saves dataset → [Python predict.py] → prediction_{SYMBOL}.json → [EA AIEngine]
                                                                            ↓
                               Weighted Score = 50% AI + 50% Technical
```

- **AI weight increased from 30% to 50%** in V1.0.
- **AI Veto** — AI can veto a trade if confidence is too low.
- **AI Lot Multiplier** — AI confidence adjusts lot size.
- **AI Feedback Logging** — Every prediction is logged for offline analysis.

## Risk Management

| Feature | Description |
|---|---|
| **Equity Protection** | Monitors equity drawdown; triggers emergency close-all if drawdown exceeds threshold. |
| **Daily Loss Limit** | Stops trading for the day if accumulated losses exceed `MaxDailyLoss`. |
| **Min Equity Check** | Prevents trading if account equity falls below `MinEquityPercent` of initial balance. |
| **Drawdown-based Lot Scaling** | Reduces lot size proportionally as drawdown increases. |
| **Break-even (ATR)** | Moves SL to break-even (plus ATR buffer) once price moves favorably. |
| **Trailing Stop (ATR)** | Trailing stop based on ATR with minimum distance enforcement. |
| **CanTradeToday** | Prevents trading on high-impact news days or after daily loss limit. |
